# V8.1 Import Engine — Panduan Operasional

## Prinsip
Excel yang diimpor diperlakukan sebagai sumber struktur. Dashboard membaca nilai dan formula untuk analitiknya sendiri, sementara workbook template terakhir disimpan agar export dapat mempertahankan layout Excel sebanyak mungkin.

## Alur import
1. Pilih **Import Excel**.
2. Sistem membaca seluruh sheet tanpa langsung mengubah database.
3. Modal **Pratinjau & validasi** menampilkan jumlah sheet, formula, error, referensi eksternal, dan hasil schema mapping.
4. Pilih mode:
   - **Perbarui TA aktif** — update tahun yang sedang dibuka.
   - **Import sebagai TA baru** — gunakan tahun yang terdeteksi pada file.
   - **Gabungkan sheet** — update sheet yang cocok dan pertahankan sheet lainnya.
5. Biarkan **Pertahankan format Excel** aktif untuk memakai workbook sumber sebagai template export.
6. Tekan **Validasi OK • Terapkan Import**.
7. Sebelum perubahan diterapkan, database lama otomatis dicadangkan.
8. Setelah berhasil, audit import dicatat di localStorage.

## Schema mapping
Pemetaan memiliki empat status:
- **COCOK** — nama sheet sama.
- **FLEKSIBEL** — nama berbeda tetapi cukup mirip, misalnya variasi spasi/tanda kurung/penamaan.
- **HILANG** — sheet yang diharapkan tidak ditemukan.
- **BARU** — sheet ada di Excel tetapi belum ada di database website.

Import tidak langsung menimpa database ketika preview sedang ditampilkan.

## Validasi formula
Audit menghitung:
- jumlah formula
- nilai error seperti `#REF!`, `#DIV/0!`, `#VALUE!`, `#NAME?`, `#N/A`
- formula dengan referensi eksternal `[Workbook]...`

Nilai cache dari formula eksternal dipertahankan bila tersedia. Sistem tidak mengarang hasil formula eksternal yang sumbernya tidak ada.

## Preservasi format
Template workbook terakhir menyimpan metadata dan digunakan sebagai dasar export. Yang dipertahankan sebisa mungkin:
- merge
- lebar kolom
- tinggi baris
- view
- autofilter
- formula cell
- struktur sheet

Catatan: kompatibilitas style Excel tertentu tetap bergantung pada kemampuan library XLSX yang digunakan di browser. Untuk fidelity penuh 1:1 terhadap seluruh style Excel (mis. conditional formatting kompleks, pivot, chart, named range), diperlukan engine Excel server-side.

## Rollback
Setiap import yang diterapkan membuat backup otomatis. Tombol **Batalkan import** mengembalikan database ke snapshot sebelum import terakhir dan menulis audit rollback.

## Audit
Audit disimpan lokal dengan key:
`mahulu-dashboard-realisasi-kinerja-v8:importAudit`

Backup import terakhir:
`mahulu-dashboard-realisasi-kinerja-v8:importBackup`

Template workbook:
`mahulu-dashboard-realisasi-kinerja-v8:excelTemplate`


## V8.1.3 calculation correction
`Realisasi Fisik & Keu` now treats E (Realisasi Fisik %) as an automatic derived value. The Excel template formula `E = I/D*100` is implemented as the algebraically equivalent `E = H` to avoid circular dependencies. Detail G remains a source value from Excel/import; G on program and office totals is automatically aggregated.


### V8.1.5 duplicate protection
The application canonicalizes stored and imported sheet names before rendering or mapping. Equivalent aliases are merged into one canonical sheet; non-empty data is preserved, and genuinely new sheet names remain available.
