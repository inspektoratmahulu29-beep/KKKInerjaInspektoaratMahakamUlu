# Web 2 V9.3 — Operations

## Environment
- `ADMIN_USERNAME` — Variable
- `DEFAULT_YEAR` — Variable
- `GOOGLE_SHEETS_SPREADSHEET_ID` — Variable
- `ADMIN_PASSWORD` — Secret
- `SESSION_SECRET` — Secret
- `GOOGLE_SERVICE_ACCOUNT_JSON` — Secret

## Import flow
1. Operator logs in.
2. Excel is parsed locally and previewed.
3. Schema mapping is shown before apply.
4. Backend verifies Google Sheets access.
5. Backend creates missing target tabs.
6. Existing target values are snapshotted.
7. Values are cleared and written in small batches.
8. If a write fails, backend attempts remote restore.
9. A revision marker is updated in hidden `__SYSTEM`.

## Autosave
After an edit, the browser waits ~1.8 seconds before saving to the backend. Failed saves keep the local draft and mark the UI as `GAGAL SINKRON`; they are not silently discarded.

## Realtime cooperation
Web 2 polls its lightweight revision endpoint every 3 seconds when clean. If the revision changes, it refreshes the current year. The public Web 1 remains read-only and must never receive service-account credentials.

## Security
Service-account JSON and session secret never belong in `src/`, `public/`, GitHub, or browser localStorage. Only the browser's local draft copy of workbook data may be stored in IndexedDB.
